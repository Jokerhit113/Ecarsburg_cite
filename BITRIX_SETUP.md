# Настройка формы консультации и Bitrix24

1. Установите зависимости: `pip install -r requirements.txt`.
2. Создайте файл `.env` рядом с `app.py` по образцу `.env.example`.
3. Укажите в `BITRIX_WEBHOOK_URL` адрес входящего вебхука Bitrix24 с разрешением `crm.lead.add`. Не публикуйте `.env` и не добавляйте его в архив/репозиторий.
4. Перезапустите Flask-приложение.
5. Откройте главную страницу и отправьте тестовую заявку. Проверьте появление лида в CRM.

Форма передаёт имя, телефон, обязательное согласие и промокод из параметра `?ref=...` в URL. Если `ref` отсутствует, используется `ECARSBURG`. Поле EMAIL намеренно оставлено как `test@mail.ru` по требованию заказчика.

При ошибке Bitrix24 посетитель увидит безопасное сообщение и сможет попробовать повторно; подробности записываются в журнал приложения. Настройте HTTPS для сайта и ограничьте доступ к файлу `.env`.
